# Precision of Physics (POP) 🔬

High-Precision Physical Metrology & Historical Science Suite.

Precision of Physics (POP) is an interactive physical metrology simulation and educational suite. It provides real-time virtual simulations, zero-error compensation, mathematical formulations, and step-by-step reading calculation for fundamental physics laboratory instruments.

---

## 🛠️ Instruments Included

1. **Vernier Caliper**
   - Least count calculation ($0.1\text{ mm}$)
   - Positive and negative zero-error compensation
   - Virtual slider simulation with sample test objects
2. **Screw Gauge (Micrometer)**
   - Circular scale division and pitch measurement ($0.01\text{ mm}$ least count)
   - Real-time rotating thimble and ratchet simulation
   - Wire and sheet thickness evaluation
3. **Spherometer**
   - Three-legged equilateral base with central micrometer screw
   - Sagitta ($h$) elevation and radius of curvature ($R$) determination
   - Convex and concave spherical lens measurement
4. **Indian Knowledge System (IKS) Metrology**
   - Historical metrology references from the Sulba Sutras and Kautilya's Arthashastra
